## 1. 제품 정의

플레이어의 캐릭터가 **체스말이 되어** 보드 위에서 싸우는 **PvE 우선 로그라이크**.

핵심 구조 한 줄: **보유한 체스말 = 목숨. 어느 말로 싸울지는 내가 못 고른다.**

- 런 시작 시 보유 말 중 **하나가 랜덤 배정**됨 (플레이어 선택 불가)
- 그 말 **1기**로 싸움
- 죽으면 → **남은 보유 말 중 또 랜덤** 배정 → 런 계속
- 보유 말을 전부 소진하면 런 종료
- 플레이로 번 재화로 말을 사면 → **목숨이 늘고 런이 깊어짐**

말들은 **이동·기동성에는 위계가 있으나(예: Queen이 Knight보다 넓게 움직임), 특수능력과 확률적 전투 해결로 상위 말이 하위 말을 반드시 이기지는 않습니다** (§4.3·§5.3.1). 가격은 단일 난이도 축이 아니라 **두 종류의 프리미엄**을 반영합니다 — "강하지만 위험해서"(Queen: 전방위 공격, 피격 ×1.5) 비싸거나, "약하지만 안전해서"(King: 피격 ×0.5) 비쌉니다 (v0.4 — §5.3).

### 4.1 "말 = 목숨"이 해결한 것

초기 설계 검토에서 지적된 모순: *가격 사다리 + 랜덤 배정 = 비싼 말을 살수록 체감 손해*(6개 보유 시 킹을 6번에 1번만 플레이, 폰은 버릴 수 없는 부채).

**목숨 구조가 이를 제거합니다.** 말 구매는 추첨 확률 희석이 아니라 **목숨 추가**이므로 언제나 명확한 이득이고, 폰도 부채가 아니라 여분 목숨입니다. 부수 효과로 **말이 죽을 때마다 플레이스타일이 강제로 바뀌어** 한 런 안에서 변주가 생깁니다.

### 4.2 코스메틱 전용 결정의 근거

- **Tower Defense Simulator**: 코스메틱 크레이트 중심으로 **7년 · 48.6억 방문 · CCU 21,357 안정**. 45개 세트에서 **붕괴도 급등도 안 한 유일한 타이틀**.
- **규제 리서치**: `random power + 미성년자 + 루트박스` = 최대 노출 조합.
- **플레이어=체스말**이라 모든 코스메틱이 상시 노출 → 코스메틱 수익화 전제 충족.

**트레이드오프**: ARPDAU 상한이 낮음. **"12~18개월 스파이크 후 사망" 대신 "느리지만 durable"**을 선택.

### 4.3 확률적 전투 도입 — "사이드그레이드" 재정의 (v0.3)

데빌스 애드버킷 검증(2026-07-23, 체스 전문가 3 + 엔지니어 3 렌즈)에서 v0.2의 "사이드그레이드(강약 없음)" 주장이 **자체 데이터와 모순**됨이 확인됐습니다 — §5.3 표 자체가 4×4에서 Queen 기동성이 Knight의 3.17배임을 보여주는데 "강약 없다"고 서술했습니다.

**v0.3 결정**: 위계가 있다는 사실을 인정하고, 대신 **전투 해결을 확률화**해서 상위 말이 하위 말을 반드시 이기지 않게 만듭니다. 이동 규칙은 그대로 두고 각 기물에 **특수능력**(§5.3.1)을 부여하며, 이 능력이 기준 크리티컬 확률(15%)을 보정합니다.

**이게 해결하는 것**: "사이드그레이드" 주장을 거짓 서술 없이 정직하게 성립시킵니다 — 위계는 있되 전투 결과는 결정적이지 않습니다.

**보드를 6×6 고정**으로 바꾼 결정(§4·§5.1)과 결합하면 특히 강력합니다. 기동성 격차가 더 이상 레벨마다 발산하는 움직이는 표적이 아니라 **상수**(Queen:Knight=3.66배, Rook:Knight=2.27배, King:Knight=1.39배, 전부 6×6 고정값)이므로, 크리티컬 확률 보정으로 이 고정 격차를 메우는 밸런싱이 결정론 시뮬로 훨씬 다루기 쉬워졌습니다.

**결정론 호환성**: 크리티컬 판정은 시드 기반 RNG를 서버 상태로 취급하여 §9의 결정론적 리플레이 설계와 호환됩니다.

| **턴** | 플레이어가 **내 말의 이동 규칙대로 갈 칸을 선택**(적이 있는 칸도 목적지로 선택 가능 = 그 자체가 공격, v0.4 확정) → 이동 → **전투 자동 해결** → 적 턴(이동만, 데미지는 플레이어 이동 트리거 전용 — v0.4 확정, 아래 참조) |
| **레벨 클리어** | 해당 레벨의 적 말 전멸 시 다음 레벨 |
| **레벨 상승** | **보드 크기는 그대로. 적 수·스탯만 증가, 단 적 수는 반드시 유한 상한** (v0.4 — 아래 참조) |
| **사망** | 남은 보유 말에서 **또 랜덤 배정** → 이어서 진행 (도달 레벨 유지). **인접 적 0개인 최원거리 칸으로 텔레포트 + 배정 직후 1턴 무적** (v0.5, 아래 참조) |
| **런 종료** | 보유 말 전부 소진 |
| **정산** | 도달 레벨 기준 경험치·재화 지급 |

**난이도 곡선** (v0.3 — 보드 **6×6 고정**, 36칸):

| 레벨 | 보드 | 적 수 (예시, 시뮬 튜닝 대상) |
|---|---|---|
| 1 | 6×6 | 1~2 |
| 2 | 6×6 | 증가 |
| 3 | 6×6 | 증가 + 스탯 상승 |
| n | 6×6 | 증가, **상한 도달 후 스탯만 증가** (v0.4) |

**v0.2 → v0.3 변경 이유**: 원래는 레벨마다 판이 (n+3)×(n+3)로 커지는 구조였으나, 데빌스 애드버킷 검증에서 이게 **기동성 격차의 무한 발산**(Rook 기동성 = 2(n-1) 공식, n이 커질수록 격차도 무한 확대)과 **근접 말 누적 난이도 스파이크**(King 커버율이 레벨마다 32.5%→23.2%→16.9%로 추락)의 원인으로 지적됨. **판을 고정하면 두 문제가 모두 사라집니다** — 격차가 상수가 되므로 §4.3의 확률적 전투 시스템으로 다루기 쉬워짐. 6×6을 고른 이유: Knight 최소 기동성이 2로 안전(3×3의 소프트락 없음), §5.3 표에서 이미 계산된 값 재사용 가능.

**3×3·4×4를 안 쓰는 이유**는 §5.3 계산 근거 — Knight가 3×3 중앙에서 합법 이동 0개가 되어 소프트락됩니다. 6×6은 이 문제에서 안전하며 판 하나로 계속 플레이하므로 **매 레벨 새 판 지형을 학습할 필요가 없어 조작이 더 직관적**입니다.

#### 🔴 적 수는 반드시 유한 상한이 있어야 함 (v0.4, 비둘기집 원리로 증명됨)

"레벨마다 적 수 계속 증가"를 **말 그대로 무상한**으로 두면, 보드가 영구히 36칸(플레이어 1칸 제외 35칸 가용) 고정인 이상 **비둘기집 원리로 반드시 "필요 적 수 > 35"인 레벨이 존재**합니다. 그 레벨은 어려운 게 아니라 **스폰 자체가 물리적으로 불가능**합니다. 곡선을 아무리 완만하게 잡아도(예: 적 수=레벨+1) 문제를 늦출 뿐 제거하지 못합니다 — 보드가 다시 커지지 않기 때문(§5.1 v0.3에서 고정한 이유 그대로).

**✅ 확정**: 적 수 스케일링에 **명시적 점근 상한**을 둡니다(정확한 값은 §12 결정론 시뮬 튜닝 대상, 6×6에서 10~14선 근방으로 잠정). 상한 도달 후 난이도는 **적 기물 등급 상승**으로 전환합니다(v0.6 — 아래 §5.1.1 참조). 스폰 스케줄러에 "가용 칸 초과 시 레벨 거부" 가드를 필수 요구사항으로 추가.

#### 5.1.1 적 수 상한 이후 — 기물 등급 상승 + King 클리어 + 초월(프레스티지) (v0.6 신규)

적 수가 상한에 도달하면, **그 이후로는 적 수를 고정하고 대신 적 "기물 등급"을 올립니다.** 적도 플레이어와 동일한 6종 기물 무브셋 + 특수능력 테이블(Bishop 색맹, Queen 취약 ×1.5, King 철벽 ×0.5 등, §5.3/§5.3.1)을 그대로 재사용합니다 — 별도 적 전용 밸런스를 새로 만들지 않습니다.

```
적 수 증가 (레벨 1..N, 상한까지) → 상한 도달, 적 수 고정
  → 적 기물 등급 상승: Pawn급 → Knight급 → Bishop급 → Rook급 → Queen급 → King급
  → King급 적 전멸 시 그 런(스테이지) 클리어 — 로스터 소진 사망과는 별개의 "승리 종료" 조건
```

> ⚠ **Bishop 색맹 규칙이 적에게도 대칭 적용됩니다.** 적 스폰 색 제한(§5.3)은 이미 "말 타입에 무관하게 모든 적 스폰"에 적용되므로, 별도 신규 규칙 없이 적 Bishop도 자동으로 보호됩니다 — 명시만 해두면 충분합니다. (아니었다면: 플레이어 Bishop과 적 Bishop이 반대색에 있으면 서로 영원히 닿지 못하는 상호 교착 상태가 생겼을 것.)

**초월 레벨 (프레스티지, v0.6 확정)**: 스테이지 클리어(King급 처치) 후, 플레이어는 **같은 진행 사다리를 더 어렵게 재도전**할 수 있습니다.
- **보유 로스터(말)는 초월 레벨 전환 시 유지**됩니다 — 완전 리셋 프레스티지가 아니라 **난이도 선택에 가까운 구조**(벤치마크 Anime Card Clash의 Nightmare Mode 패턴과 동일 계열, §6).
- 적 스탯 배율이 초월 레벨 번호에 연동됩니다: **초월 레벨 1(기본) = ×1, 초월 레벨 2 = ×2.** `[Medium]` 3 이상의 정확한 곡선(계속 선형 ×N인지, 다른 곡선인지)은 두 지점만 확정됐으므로 **작업 가설** — §12 결정론 시뮬 대상.
- 적 수 상한·기물 등급 사다리 자체는 초월 레벨과 무관하게 동일하게 반복됩니다. 초월 레벨은 오직 **스탯 배율**만 바꿉니다.

**스코프 판단**: 이 시스템 전체(기물 등급 상승·King 클리어·초월 레벨)는 **v1**입니다. MVP는 여전히 "죽을 때까지"만 보는 순수 리텐션 검증 루프이고(§3.2), 여기에 승리 조건·프레스티지까지 얹으면 MVP가 검증하려는 단일 가설이 흐려집니다. MVP 3종(Pawn/Knight/Rook)은 적 수 상한·King 클리어 없이 기존 v0.5 방식(상한 후 정체, 로스터 소진까지 생존) 그대로 갑니다.

#### 전투 트리거 규칙 확정 (v0.4)

두 가지 모호성이 있었습니다 — 둘 다 확정합니다.

**① 목적지가 적이 있는 칸이어도 이동 가능(capture-and-land).** 인접만으로 전투가 트리거되고 적이 칸에 남아있다는 해석(occupied square = 비합법 목적지)이면, 코너에 몰린 기물의 모든 합법 목적지가 동시에 적으로 막히는 순간 **그 턴 합법수가 진짜 0**이 됩니다 — King(코너 3칸)·Knight(코너 L-타겟 2칸)·Pawn(코너 2칸) 전부 취약. **정통 체스처럼 "적이 있는 칸으로 이동 = 그 적을 공격"으로 확정**하면 이 문제가 구조적으로 사라집니다.

**② 적 턴 = 이동만. 데미지는 플레이어 자신의 이동이 트리거할 때만 발생.** 이미 인접한 적이 매 적턴마다 독립적으로 공격하는지, 플레이어가 새로 붙인 순간에만 전투가 발생하는지가 불명확했습니다. **후자로 확정** — §5.4 "보드 위 판단이 실력"이라는 핵심 철학과 정합적입니다(가만히 있으면 안전, 접근이 곧 리스크 계산). 적 턴에는 적들이 이동만 하고(§12 적 AI 행동 규칙과 함께 설계), 데미지는 플레이어가 자기 턴에 적 칸으로 이동(공격)할 때만 양방향으로 발생.

#### 슬라이딩 기물 차단 규칙 확정 (v0.4)

Rook·Bishop·Queen이 이동 경로상 **다른 말(적)에 막히는지**가 미정이었습니다. 두 분기 다 문제가 있었습니다: **막히지 않음**이면 Knight의 "직선 차단에 강함" 트레잇이 아무 의미 없어지고(막힐 대상 자체가 없음), **막힘**이면 Rook·Bishop의 관통(pierce) 능력이 이동 경로만으로는 원천적으로 불가능(첫 적에서 멈추는 게 BLOCKED의 정의 자체).

**✅ 확정: BLOCKED 채택.** 정통 체스처럼 슬라이딩 기물은 경로상 첫 번째 말(적)에서 멈춥니다 — 이래야 Knight의 "차단 무시" 트레잇이 실체를 갖습니다. **Rook·Bishop의 관통(pierce)은 이 차단 규칙의 명시적 예외 능력**으로 문서화합니다 — "이동으로 재현 가능한 결과"가 아니라 "차단을 뚫는 별도 전투 효과"입니다. §5.3.1의 관통 서술을 이 원칙에 맞춰 읽습니다.

#### 안전 리스폰 규칙 확정 (v0.5)

사망 후 리드로우된 말(특히 저방어 Queen, 피격 ×1.5)이 적에 둘러싸여 한 번도 움직이지 못하고 죽는 문제 — **두 완화 조치를 동시에 적용**합니다.

1. **최원거리 텔레포트**: 재배정 즉시, 인접 적 0개인 칸 중 **가장 먼 칸**으로 위치를 옮깁니다(순간이동, 사용자 입력 없음).
2. **1턴 무적**: 재배정 직후 첫 턴 동안 피격 데미지 무효.

두 장치는 서로 다른 실패 모드를 막습니다 — 텔레포트는 "애초에 안 붙게" 하고, 무적은 "그래도 붙었을 때"(예: 다음 레벨로 넘어가며 좁아진 잔여 공간, 적 재배치 등)를 방어합니다.

#### 강제 이동 + Zugzwang 대응 확정 (v0.5)

매턴 이동이 강제이고 pass가 없어서, 저기동성 기물이 "선택은 있으나 전부 손해"인 상태(체스의 zugzwang)에 몰릴 수 있다는 문제 — hold 액션 추가는 §5.4가 이미 잠근 "플레이어 추가 조작 없음" 규칙과 충돌하므로 **제외**하고, 다음 두 가지로 대응합니다.

1. **스폰 규칙 보장**: 적 스폰·이동 로직은 활성 기물에게 **항상 비인접 합법 목적지 1개 이상**을 남기도록 설계합니다(§12 적 AI 행동 규칙에 필수 요구사항으로 포함). 완전한 zugzwang(모든 선택지가 손해) 자체는 남을 수 있으나, **적어도 도망칠 구멍은 항상 존재**합니다.
2. **데미지 프리뷰 UI**: 이동 전 각 목적지 선택 시 예상 피해/생존 확률을 미리 보여줍니다. 손해를 막지는 못하지만 "왜 손해인지"를 투명하게 드러내 어린 유저의 "불공정하다"는 체감을 줄입니다.

### 5.3 기물별 플레이스타일

체스 기물의 **이동 규칙을 전투 문법으로 전환**. 이동·기동성에는 위계가 있으나(아래 표), **특수능력(§5.3.1)과 확률적 전투 해결(§4.3)**로 상위 말이 하위 말을 반드시 이기지는 않습니다.

| 기물 | 스타일 | 전투 문법 |
|---|---|---|
| Pawn | 근접·정직 | **4방향 중 1칸 이동** (v0.4 확정 — 고정 전진 방향은 PvE에 정의 없고 판 가장자리 소프트락 유발. §5.3 하단 참조). 조건 충족 시 승격 (승급 조건 미정 — §12) |
| Knight | 도약·기습 | L자 이동으로 전열 무시, 후방 접근. 직선 차단에 강함 |
| Bishop | 사선·관통 | 대각선 라인. **판 36칸 중 자기 색 18칸만 영원히 도달 가능**(색맹 구조, 아래 참조) |
| Rook | 직선·압박 | 직선 라인 관통. 정렬로 광역 처리 |
| Queen | **전방위·최약 방어** | 전 방향 공격 가능(v0.4 헤드라인) — 대신 **구조적으로 가장 잘 맞음**(피격 데미지 항상 ×1.5) |
| King | **저사거리·최강 방어** | 인접 1칸만. 대신 **구조적으로 가장 안 맞음**(피격 데미지 항상 ×0.5, v0.4 헤드라인). **가장 비싼 말** |

> **King이 가장 비싼 이유 — v0.4 재정의.** 이전 서술("가장 어렵다")은 기동성 표와 충돌해 데빌스 애드버킷이 지적한 미해결 항목이었습니다. v0.4에서 King에게 **항상 켜진 최강 방어**(피격 ×0.5)를 부여하면서 이 모순이 더 깊어집니다 — 방어가 세면 실수 비용이 줄어 오히려 **다루기 쉬운 말**이 됩니다. **가격 논리를 교체**합니다: King은 "어려워서"가 아니라 **"가장 안전해서"** 비쌉니다(방어형 보험 픽 — 낮은 분산, 낮은 화력, 높은 생존). 반대로 Queen은 "강하지만 위험해서"(높은 화력·기동성, 최약 방어) 비쌉니다. 가격 = 난이도 게이트라는 단일 서술 대신, **기물마다 "위험한 강함"과 "안전한 약함" 두 가지 프리미엄 축**을 인정하는 것으로 §4의 가격 논리를 수정합니다.

Pawn은 v0.3까지 이동 규칙이 정의되지 않아 표에서 빠져 있었습니다. **v0.4에서 "4방향 중 1칸"으로 확정**(아래 참조) — 최소 기동성 2로 안전, 3×3 Knight 소프트락과 같은 함정 없음.

이 표는 이제 "레벨마다 격차가 어떻게 변하는가"가 아니라 **"왜 6×6을 골랐는가"**를 뒷받침합니다 (§5.1 v0.3 변경 참조).

1. **3×3은 Knight를 소프트락시킵니다.** 중앙 합법 이동 **0개** — L자 이동이 전부 판 밖. **4×4부터 최소 2로 회복**되고 6×6에서도 유지됩니다.
2. **6×6 고정 기준 격차는 이제 상수입니다**: Queen:Knight = 16.1/4.4 = **3.66배**, Rook:Knight = 10.0/4.4 = **2.27배**, King:Knight = 6.1/4.4 = **1.39배**. 판이 더 이상 커지지 않으므로(§5.1) 이 비율은 레벨과 무관하게 고정됩니다 — §4.3의 크리티컬/특수능력 보정이 메워야 할 **고정 표적**입니다.

#### Pawn 이동 규칙 확정 (v0.4)

정통 체스의 "고정 전진"은 2인 대전을 전제로 방향이 명확하지만, 이 게임은 **PvE에서 적이 사방에서 스폰**되므로 "전진"이 정의되지 않습니다. 두 해석을 계산 검증했습니다:

| 해석 | 평균 기동성 | 최소 기동성 |
|---|---:|---:|
| 고정 전진만 (정통 체스) | 0.83 | **0** (판 가장자리에서 소프트락) |
| **4방향 중 1칸 (채택)** | **3.33** | **2** |

고정 전진 해석은 3×3 Knight 소프트락과 동일한 함정(합법 이동 0개)을 판 가장자리에서 재현합니다. **4방향 중 1칸으로 확정** — 최소 2 확보, PvE 논리에도 부합(적이 어디서 오든 대응 가능).

#### 🔴 Bishop 색맹 구조 결함 (v0.4 신규 발견, 계산 검증됨)

대각선 이동은 **판의 색(체스 좌표 패리티)을 절대 바꾸지 않습니다.** BFS로 다중 이동 누적 도달 범위를 계산한 결과:

```
Bishop 누적 도달 칸 (몇 수를 두든): 18 / 36 (정확히 절반)
Rook·Knight 누적 도달 칸: 36 / 36 (전체)
```

**말 1기 = 목숨**인 이 게임에서, Bishop이 배정된 목숨은 **반대 색 칸에 스폰된 적에게 이동으로도 관통 공격으로도 영원히 도달 못 합니다** — 관통도 대각선을 타므로 같은 색만 훑습니다. 방치하면 소프트락.

**✅ 채택된 완화안**: **Bishop이 배정된 동안 적 스폰을 Bishop과 같은 색 칸으로 제한**합니다. 체스 정통성 유지, 구현 가장 간단. 적 스폰 시스템(§12, 적 AI 행동 규칙과 함께 미정)에 이 제약을 필수 요구사항으로 추가.

**🔴 이 완화안 자체의 두 가지 구멍 (v0.4 브레인스토밍에서 발견, 계산 검증됨) — 함께 확정합니다:**

1. **말 교체 시점의 잔존 적 문제.** "스폰 시점에 제한"만으로는 부족합니다 — 레벨 도중 Bishop이 아닌 말(예: Rook)이 적을 일부만 죽이고 죽어서, 다음 랜덤 배정이 Bishop이면 **남은 적은 Rook이 살아있을 때 스폰된 것이라 색 제한이 적용 안 됐을 수 있습니다.** ✅ **확정**: 활성 말이 Bishop으로 바뀌는 순간, 반대색에 있는 잔존 적을 **같은 색 칸으로 재배치**합니다(HP·상태는 유지 — 새로 생성 아님, 위치만 이동).
2. **캐파 상한 + 밀도 택스.** 6×6=36칸은 색상으로 정확히 18/18 양분되고 플레이어가 1칸을 차지하므로 **Bishop 레벨의 실질 가용 칸은 17칸**(다른 기물은 35칸) — 위 적 수 상한과 결합하면 Bishop 레벨은 **다른 기물 대비 항상 2배 밀도**가 됩니다. ✅ **확정**: Bishop이 활성일 때는 적 수 상한을 **다른 기물의 절반**으로 적용(밀도를 맞추기 위함), 난이도는 부족분만큼 스탯으로 보정.

#### 5.3.1 특수능력 시스템 (v0.3 신규)

이동 규칙은 그대로 두고, 각 기물의 **기본 공격 위에 특수능력**을 얹어 전투 결과에 확률적 변수를 만듭니다. 모든 특수능력은 **자동 발동**(이동 패턴에 결부, 플레이어 추가 조작 없음) — 턴제 이동 선택 하나로 조작 부담을 늘리지 않습니다.

**기준 크리티컬 확률: 모든 말 공통 15%.** 특수능력은 이 기준값을 보정합니다.

| 기물 | 특수능력 | 효과 | 스코프 |
|---|---|---|---|
| Pawn | 없음 | 기본 공격만 (기준점) | MVP |
| Knight | 돌진 공격 | L자 이동으로 도착·공격 시 크리티컬 확률 **2배 (30%)** | MVP |
| Rook | 관통 공격 (작업 가설) | 직선 경로상 첫 번째 적 관통 시 두 번째 적까지 피해 | MVP |
| Bishop | 장대각 조준 (작업 가설) | 이번 턴 대각 이동거리 기반 크리티컬: `min(15% + 5%×(거리−1), 30%)`. 나이트 고정값(30%)에서 캡 — 하위 기물의 상한을 못 넘음 | v1 |
| Queen | **전방위 취약** (v0.4 헤드라인) | 특수 공격 없음(전 방향 공격은 이동 규칙 자체에서 이미 나옴) — 대신 **피격 데미지 항상 ×1.5**. 안전 플레이로 회피 불가능한 영구 세금 | v1 |
| King | **철벽** (v0.4 헤드라인) | 공격 보정 없음 — **피격 데미지 항상 ×0.5**. 가장 비싼 이유가 "어려움"이 아니라 "안전"으로 재정의됨(§5.3) | v1 |

Rook의 "관통 공격"과 Bishop의 계수·캡은 확정 수치가 아니라 **작업 가설**입니다 — §12의 결정론 시뮬 실험으로 실제 승률 곡선을 뽑은 뒤 조정합니다. Queen·King의 ×1.5/×0.5는 애초 조건부(이동거리·HP 임계값) 설계로 교차검증됐던 배율을 그대로 재사용해 **항상 켜짐**으로 단순화한 것 — 임계값 설계보다 안전 플레이로 회피할 구멍이 없어 오히려 더 견고합니다.

**공유 전투 변수 3개** (v0.4 확정): 각 기물의 특수능력은 이 중 정확히 하나만 조정합니다 — ① **크리티컬 확률**(Knight·Bishop) ② **관통 대상 수**(Rook) ③ **피격 데미지 배율**(Queen·King). 새 서브시스템을 만들지 않고 기존 세 레버 안에서만 움직입니다.

> ⚠ **이 시스템이 해결하는 범위는 제한적입니다.** 특수능력·크리티컬은 **전투가 성사된 이후의 결과**만 확률화합니다. King·Knight처럼 이동 범위가 좁은 말이 **적에게 도달하기까지 걸리는 턴수**(reachability) 문제는 별개입니다. 다만 보드를 6×6으로 고정한 덕분(§5.1 v0.3)에 이 문제도 더 이상 레벨마다 무한히 나빠지지 않고 **유한한 값으로 고정**됩니다 — 여전히 존재하지만 발산하지는 않습니다.

> ⚠ **크리티컬 발동 시 피해 배율은 아직 미정입니다** — 지금까지 정의된 건 크리티컬 **확률**(15%/30%/거리비례)뿐, 크리티컬이 터졌을 때 데미지를 몇 배로 줄지는 없습니다. 절대적인 전투력 계산은 이 값 없이는 불가능합니다 `[신규, §12]`.

### 5.4 플레이어 행위 주체성 — 해결됨

**턴제 이동 선택으로 확정.** 플레이어는 매 턴 자기 말의 체스 이동 규칙 안에서 **갈 칸을 고르고**, 전투는 자동 해결됩니다.

이 결정이 기획 전체를 지탱합니다:
- **"보드 위 판단이 실력"** 근거가 성립합니다. 이동 선택이 곧 의사결정 표면.
- **기물 정체성이 실제로 중요해집니다.** Knight의 선택지와 Rook의 선택지는 완전히 다른 퍼즐이므로, 말이 바뀌면 게임이 바뀝니다 — "말 = 목숨" 구조의 변주가 여기서 나옵니다.
- **턴제라 서버 권위 구현이 저렴합니다.** 실시간 위치 검증이 불필요하고, 합법 이동 검증만 서버에서 하면 됩니다.

시작 보드 크기 이슈는 **6×6 고정으로 해결**됐습니다(§5.1 v0.3) — 3×3 소프트락 회피와 기동성 격차 상수화를 동시에 달성.

## 8. 컴플라이언스 — 필수 엔지니어링 (협상 불가)

> **코스메틱 가챠도 규제 면제가 아닙니다.** Roblox "Paid Random Items" 정책은 Robux(및 Robux 파생 재화)로 구매하는 **모든** 무작위 아이템에 적용됩니다.

| 요구사항 | 구현 |
|---|---|
| 확률 공시 | 모든 결과 + **실제 수치 확률, 합계 정확히 100%**, **구매 전** 노출 |
| 정책 API | `PolicyService:GetPolicyInfoForPlayerAsync()` **호출 필수** |
| 지역 제한 | `ArePaidRandomItemsRestricted` 준수 → **비무작위 대체 경로 필수** |
| 거래 제한 | `IsPaidItemTradingAllowed` 준수 |
| 미준수 결과 | **해당 지역에서 게임 자동 이용불가** |

**현재 차단 지역**: 영국 18세 미만, **호주 전체 유저**. 확대 추세.

**한국**: 게임산업진흥법 법률 제19242호(2024-03-22 시행). **간접 구매**(Robux로 산 게임 내 재화)까지 포함. 위반 시 최대 징역 2년 / 벌금 2,000만원. 연평균 매출 1억원 이하 소규모 사업자 면제.

**설계 반영**: 확률 테이블을 **데이터로 정의**하고 클라이언트 렌더, **배너별 버전 관리**. 비무작위 경로(색상·장식 직접 구매)를 차단 지역 대응 경로로 승격. `[Medium]` 출시 전 법률 검토 필요 — 본 문서는 법률 자문이 아님.

## 9. 기술 아키텍처

`00_VS`의 코드를 복사하지 않고, **동일 스택·패턴으로 `01_Chess/`에 신규 스캐폴딩**합니다.

### 9.1 스택
- **rokit** 툴체인 핀: rojo 7.7.0 / lune 0.10.5 / selene 0.31.0 / stylua 2.5.2
- Rojo 소스 트리 → `.rbxlx` 빌드
- Lune 기반 **dual-runtime 테스트**

### 9.2 원칙
- **서버 권위**: 전투 판정·보상·재화·구매·랜덤 배정 전부 서버 소유. 클라이언트 결과 불신.
- **랜덤 배정은 반드시 서버에서.** 클라이언트가 배정을 굴리면 원하는 말이 나올 때까지 재시도하는 치트가 성립합니다. 리롤 횟수도 서버 상태.
- **순수 결정론 Rules 모듈**: Roblox 인스턴스 의존 0 → 단위 테스트 가능.
- **전투 확률(크리티컬 등)도 결정론 대상.** 시드 기반 RNG를 런 상태의 일부로 취급 — 같은 시드는 같은 특수능력·크리 결과를 재현. RNG 소비 순서까지 상태에 포함해야 §9.3 리플레이가 깨지지 않음.
- **RemoteEvent 토큰 검증**: 클라이언트는 서버 발급 토큰 + 선택지 ID만 제출.
- **속성 기반 리플리케이션**: 권위 상태는 서버 전용.
- **DataStore**: 보유 말·재화·진행도·dex·Elo·코스메틱 소유권 영속화.
- **MarketplaceService**: 게임패스/개발자상품 + 영수증 검증.

### 9.3 결정론의 부수 효과
전투가 완전 결정론이면 `(초기 상태 + 시드)`로 재현 가능 → 리플레이 공유(바이럴) · 서버 검증(안티치트) · 재현 가능한 밸런스 테스트가 **하나의 설계**에서 나옵니다.

## 12. 미결 사항

**개발 착수를 막는 항목 없음.** 아래는 구현과 병행 가능하거나 이후 단계 사항입니다.

**v0.4에서 해결됨** (참고용, §5.3/§11 본문 참조):
- Bishop/Queen/King 특수능력 확정 (장대각 조준 / 전방위 취약 / 철벽)
- King "어렵다" 서술 → "안전해서 비쌈"으로 가격 논리 교체
- Bishop 색맹 구조 결함 → 동색 스폰 제한 + 말 교체 시 잔존 적 재배치 + 밀도 보정
- Pawn 이동 규칙 공백 → 4방향 1칸으로 확정

**v0.4 브레인스토밍 2라운드에서 해결됨** (§5.1 본문 참조):
- 적 수 무상한 vs 고정 보드 (비둘기집 원리로 확정된 결함) → 명시적 점근 상한 도입
- 목적지 점유 모호성 → capture-and-land 확정
- 슬라이딩 기물 차단 규칙 미정 → BLOCKED 채택, 관통은 명시적 예외
- 적 턴 데미지 트리거 불명 → 적턴은 이동만, 데미지는 플레이어 이동 트리거 전용
- 리롤 기각 기물 처리 미정 → 폐기 아님, 풀 복귀

**v0.5 브레인스토밍 3라운드(안전 리스폰·zugzwang)에서 해결됨** (§5.1 본문 참조):
- 안전 리스폰 규칙 → 최원거리 텔레포트 + 배정 직후 1턴 무적
- 강제 이동 zugzwang → 스폰 규칙(비인접 합법수 1개 보장) + 데미지 프리뷰 UI

**남은 미결:**

1. **Elo 래더(v1) - PvP(v2 이후) 스코프 정합성** `[High, 데빌스 애드버킷]` — v1에 Elo가 있는데 PvP 자체가 없어 정의상 모순. v1 착수 전 반드시 정리.
2. **MVP 3종의 최악 케이스 검증 공백** `[Medium, 데빌스 애드버킷]` — Queen/King이 MVP에 없어 실제 최대 격차(3.66배)가 검증 안 됨. v1 게이트 조건 검토.
3. **적 AI 행동 규칙** `[Medium]` — 이동 로직(플레이어 추적 방식 등) 미정. 데미지 트리거는 확정됐으나(§5.1) 어디로 이동하는지는 아직 없음. **비인접 합법수 1개 보장**(§5.1 zugzwang 대응)도 이 시스템의 필수 요구사항으로 포함. MVP 착수 전 최소 규칙 필요.
4. **리롤 복원추출 여부** `[Medium, 데빌스 애드버킷]` — 복원 시 MVP 3종 기준 리롤 실패 확률 44.4%. 비복원 권장.
5. **폰 승급 조건** — §5.3에 "조건 충족 시" 표기만 있고 조건 자체 미정. 승급 시 목표 기물의 피격 배율(예: Queen ×1.5)을 그대로 물려받는지도 함께 정의 필요.
6. **결정론 시뮬 실험 설계** — Pawn/Knight/Rook(MVP)과 Bishop/Queen/King(v1)을 6×6에서 강제 매칭시켜 승률·생존 턴수·첫 교전까지 턴수를 측정. 특히 **Rook 과최적화 의심**, **King 철벽의 실제 체감 난이도**, **적 수 상한의 정확한 값**, **초월 레벨 스탯 배율 곡선**(3 이상도 선형 ×N인지)을 우선 검증.
7. **초월 레벨 보상 곡선** `[신규, v0.6]` — 높은 초월 레벨 클리어가 더 많은 재화를 주는지, 준다면 얼마나 — 상승 유인 설계 필요.
8. **크리티컬 피해 배율** — 크리 확률만 정의됨, 터졌을 때 데미지 배율이 없어 절대 전투력 계산 불가. 항목 6의 시뮬 설계에 포함 필요.
9. **영문 정식 제목** — 글로벌·영어 우선이므로 필요. 현재 폴더 작업명 `01_Chess`.
10. **MVP 성공 임계값** — §3.3 수치는 벤치마크 미근거 `[Low]`.
11. **말 가격 곡선** — 폰→킹 가격 배율, 첫 말 지급 여부, 초기 보유 수(= 초기 목숨 수). King이 "안전 프리미엄"으로 비싸진 지금, Queen도 "고위험 고화력 프리미엄"으로 유사하게 비싸야 하는지 검토.
12. **적 수·스탯 스케일링 곡선(상한 포함)** — 6×6 고정 보드에서 레벨당 적 수·스탯 증가율과 점근 상한의 정확한 값. 항목 6과 함께 튜닝.
13. **출시 전 법률 검토** — `[Medium]` v1(수익화) 착수 시점 필요. MVP에는 불필요(유료 무작위 없음).
