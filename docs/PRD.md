## 1. 제품 정의

플레이어의 캐릭터가 **체스말이 되어** 보드 위에서 싸우는 **PvE 우선 로그라이크**입니다.

핵심 구조 한 줄: **보유한 체스말 = 목숨. 어느 말로 싸울지는 내가 못 고른다.**

- 런 시작 시 보유 말 중 **하나가 랜덤 배정**됩니다 (플레이어 선택 불가, 리롤 1회 가능)
- 그 말 **1기**로, **턴제로 이동을 선택**하며 싸웁니다 (전투는 자동 해결)
- 죽으면 → 남은 보유 말 중 **또 랜덤 배정** → 런 계속
- 보유 말을 전부 소진하면 런 종료 (패배 종료)
- 플레이로 번 재화로 말을 사면 → **목숨이 늘고 런이 깊어짐**

말들은 이동·기동성에는 실제 위계가 있습니다(예: Queen이 Knight보다 훨씬 넓게 움직임). 하지만 **특수능력과 확률적 전투 해결** 덕분에 상위 말이 하위 말을 반드시 이기지는 않습니다. 가격은 단일 난이도 축이 아니라 **두 종류의 프리미엄**을 반영합니다 — "강하지만 위험해서"(Queen) 비싸거나, "약하지만 안전해서"(King) 비쌉니다. 자세한 근거는 §6.4.

## 2. 근거 — 왜 이 게임인가

### 2.1 갭

Roblox 1차 API로 실측한 결과, **체스 기물의 이동 규칙 자체를 전투 문법으로 쓰는 TFT형/보드 오토배틀러는 존재하지 않습니다.** 경로·레인형 자동전투 게임(Anime Expeditions, Vanguards, UTDZ, ASTD 등)은 수십 개 있으나 전부 "보드 위 위치 판단"이 아니라 "어떤 말을 보유했는가"로 승패가 갈립니다.

> ⚠ 이 게임은 원래 다수 유닛을 보드에 배치하는 TFT형으로 기획됐다가, 이후 "1기 로그라이크"(§4)로 전면 개정됐습니다. 1기 로그라이크는 TFT형보다 **더 독창적이지만 벤치마크 선례가 더 적습니다** — 경쟁은 적고 검증된 사례도 적다는 뜻입니다.

### 2.2 인접 시장 규모 (실측, `games.roblox.com/v1/games`, 2026-07-23)

| 타이틀 | CCU | 누적 방문 | 의미 |
|---|---:|---:|---|
| Tower Defense Simulator | 21,357 | 48.6억 | **코스메틱 전용의 7년 생존 증명** |
| Anime Squadron | 8,056 | 7,726만 | 현실적 base case (1년 미만) |
| The Battle Bricks | 7,420 | 1.22억 | Roblox `top-revisited` 정렬 진입 |
| Garden Tower Defense | 6,501 | 7.61억 | 어린 유저가 그리드를 이해함 |
| Anime Paradox X | 1,137 | 2,813만 | median 2025 신규 진입 결과 (하방) |

### 2.3 체스 자체는 Roblox에서 작다 (전제 검증)

| 타이틀 | CCU | 누적 방문 |
|---|---:|---:|

1.06억 방문 = 관심은 실재. 435 CCU = **리텐션 설계 부재**. 정통 체스 룰 재현으로는 안 된다는 근거입니다.

### 2.4 유닛 가챠 붕괴 곡선 (우리가 피하는 것)

| 타이틀 | 누적 방문 | 현재 CCU |
|---|---:|---:|
| All Star Tower Defense | 78.8억 | 1,395 |
| Anime Defenders | 34.3억 | **394** |
| Anime Vanguards | 20.0억 | 10,060 |

전부 유닛 가챠. 누적 수십억 방문 → CCU 수백. 원인: 가챠가 메타 전부일 때 컬렉션 완성이 곧 게임 종료.

**우리 구조가 이를 피하는 방식**: 컬렉션(말)이 *파워 사다리*가 아니라 *목숨 + 스타일 변주*이므로, 다 모아도 "이제 다 이겼다"가 되지 않습니다.

## 4. 확정 결정 요약

| 항목 | 결정 |
|---|---|
| 장르 | PvE 우선 로그라이크, 플레이어 = 체스말 |
| 판당 유닛 수 | **1기** (배정된 말 하나로 싸움) |
| 플레이어 조작 | **턴제 이동 선택** — 내 말의 체스 이동 규칙대로 갈 칸을 직접 고름. 전투는 자동 해결 |
| 보드 크기 | **6×6 고정** (레벨이 올라도 판 크기 불변) |
| 말 배정 | **보유 말 중 랜덤. 플레이어 선택 불가** |
| 말 = 목숨 | 죽으면 남은 보유 말에서 또 랜덤 배정 → 런 계속. 전부 소진 시 런 종료 |
| 리롤 | **1회** (배정 직후). 기각된 말은 폐기 아님, 즉시 풀 복귀 |
| 말 위계 | **비대칭 능력 + 확률적 전투 해결**(이동·기동성엔 위계 존재, 특수능력이 하위 말도 역전 가능하게 만듦). 가격 = 위험 프리미엄(Queen) 또는 안전 프리미엄(King) |
| 특수능력 발동 | **자동** (이동 패턴에 결부, 플레이어 추가 조작 없음) |
| 기준 크리티컬 확률 | **15%** (모든 말 공통 기본값, 특수능력이 이를 보정) |
| 말 구매 수단 | **게임 내 재화만. 현금 구매 절대 불가** |
| 수익화 | **코스메틱 전용** (공격 모션·색상·스킨) |
| 전투력 획득 | **100% 플레이** |
| 멀티플레이 | PvE 우선, PvP는 v2 이후 |
| 랭크 로스터 | **정규화 공용 풀** (전원 전체 로스터 = 동일 목숨) |
| MVP 시퀀싱 | **수익화 없이 리텐션 먼저 검증** |
| 타겟 지역 | **글로벌, 영어 우선** |
| 폴더 | `01_Chess/` 단독, `00_VS` 미접촉 |

### 4.1 "말 = 목숨"이 해결한 것

초기 설계 검토에서 지적된 모순: *가격 사다리 + 랜덤 배정 = 비싼 말을 살수록 체감 손해*(예: 킹을 6개 중 하나로 보유하면 6번에 1번만 플레이, 폰은 버릴 수 없는 부채).

**목숨 구조가 이를 제거합니다.** 말 구매는 추첨 확률 희석이 아니라 **목숨 추가**이므로 언제나 명확한 이득이고, 폰도 부채가 아니라 여분 목숨입니다. 부수 효과로 **말이 죽을 때마다 플레이스타일이 강제로 바뀌어** 한 런 안에서 변주가 생깁니다.

### 4.2 코스메틱 전용 수익화의 근거

- **Tower Defense Simulator**: 코스메틱 크레이트 중심으로 **7년·48.6억 방문·CCU 21,357 안정**. 벤치마크 45개 세트에서 **붕괴도 급등도 안 한 유일한 타이틀**.
- **규제 리서치**: `random power + 미성년자 + 루트박스` = 최대 노출 조합.
- **플레이어=체스말**이라 모든 코스메틱이 상시 노출 → 코스메틱 수익화 전제 충족.
- **트레이드오프**: ARPDAU 상한이 낮음. "12~18개월 스파이크 후 사망" 대신 "느리지만 durable"을 의도적으로 선택.

### 4.3 확률적 전투 — "위계는 있지만 결과는 결정적이지 않다"

기물별 기동성 격차는 실재합니다(§6.4). 이를 부정하는 대신, **전투 해결 자체를 확률화**해서 상위 말이 하위 말을 반드시 이기지 않게 만듭니다. 이동 규칙은 그대로 두고 각 기물에 특수능력(§6.4.3)을 부여하며, 이 능력이 기준 크리티컬 확률(15%)을 보정합니다.

보드를 6×6으로 고정한 결정(§6.2)과 결합하면 특히 강력합니다 — 기동성 격차가 레벨마다 발산하는 움직이는 표적이 아니라 **상수**(Queen:Knight=3.66배, Rook:Knight=2.27배, King:Knight=1.39배)이므로, 크리티컬 확률 보정으로 이 고정 격차를 메우는 밸런싱이 결정론 시뮬로 다루기 쉽습니다.

**결정론 호환성**: 크리티컬 판정은 시드 기반 RNG를 서버 상태로 취급하여 §10의 결정론적 리플레이 설계와 호환됩니다.

## 6. 게임플레이 시스템 상세

### 6.1 턴·전투 규칙

| 단계 | 내용 |
|---|---|
| 배정 | 보유 말 중 1개 랜덤. 플레이어 선택 불가. 리롤 1회 가능 |
| 턴 | 플레이어가 내 말의 이동 규칙대로 갈 칸을 선택 → 이동 → 전투 자동 해결 → 적 턴(이동만) |
| 레벨 클리어 | 해당 레벨의 적 전멸 시 다음 레벨 |
| 사망 | 남은 보유 말에서 또 랜덤 배정 → 이어서 진행 (도달 레벨 유지, 안전 리스폰 적용) |
| 런 종료 | 보유 말 전부 소진 (패배 종료) |
| 정산 | 도달 레벨 기준 경험치·재화 지급 |

**목적지 규칙 — capture-and-land**: 목적지가 적이 있는 칸이어도 이동할 수 있으며, 그 자체가 공격입니다(정통 체스와 동일). 이 규칙이 없으면 코너에 몰린 기물(King 코너 3칸, Knight 코너 L-타겟 2칸, Pawn 코너 2칸)의 모든 합법 목적지가 동시에 적으로 막히는 순간 그 턴 합법수가 진짜 0이 되는 소프트락이 생깁니다.

**데미지 트리거 규칙**: 적 턴에는 적이 이동만 하고, 데미지는 **플레이어 자신이 공격 이동을 할 때만 양방향으로** 발생합니다. 이미 인접한 적이 매 적턴마다 독립적으로 공격하지 않습니다. 이 규칙은 "보드 위 판단이 실력"이라는 §6.4의 핵심 철학과 정합적입니다 — 가만히 있으면 안전하고, 접근이 곧 리스크 계산입니다.

**슬라이딩 기물 차단 규칙 — BLOCKED**: Rook·Bishop·Queen은 정통 체스처럼 이동 경로상 첫 번째 말(적)에서 멈춥니다. 이래야 Knight의 "차단 무시" 정체성이 실체를 갖습니다(막힐 대상 자체가 없으면 그 트레잇이 무의미해짐). **Rook·Bishop의 관통(pierce) 특수능력은 이 차단 규칙의 명시적 예외**로 문서화합니다 — 이동으로 재현 가능한 결과가 아니라 차단을 뚫는 별도 전투 효과입니다.

**안전 리스폰**: 사망 후 리드로우된 말이 적에 둘러싸여 한 번도 움직이지 못하고 죽는 것을 막기 위해 두 조치를 동시에 적용합니다.
1. **최원거리 텔레포트** — 재배정 즉시 인접 적 0개인 칸 중 가장 먼 칸으로 이동.
2. **1턴 무적** — 재배정 직후 첫 턴 동안 피격 데미지 무효.

두 장치는 서로 다른 실패 모드를 막습니다 — 텔레포트는 애초에 안 붙게, 무적은 그래도 붙었을 때(레벨 전환으로 잔여 공간이 좁아지는 경우 등)를 방어합니다.

**강제 이동 대응(Zugzwang)**: 매턴 이동이 강제이고 pass 액션이 없어서, 저기동성 기물이 "선택은 있으나 전부 손해"인 상태에 몰릴 수 있습니다. hold(대기) 액션 추가는 "플레이어 추가 조작 없음" 원칙과 충돌하므로 채택하지 않고, 대신:
1. **스폰 규칙 보장** — 적 스폰·이동 로직은 활성 기물에게 항상 비인접 합법 목적지 1개 이상을 남기도록 설계(완전한 zugzwang 자체는 남을 수 있으나 도망칠 구멍은 항상 존재).
2. **데미지 프리뷰 UI** — 이동 전 각 목적지의 예상 피해·생존 확률을 미리 표시. 손해를 막지는 못하지만 "왜 손해인지"를 투명하게 드러내 불공정하다는 체감을 줄입니다.

### 6.2 스테이지 내 난이도 곡선

보드는 **6×6 고정**입니다(36칸, 플레이어 1칸 제외 35칸 가용). 레벨업 시 판이 커지지 않고, 대신 다음 순서로 난이도가 오릅니다.

```
레벨 1..N: 적 수 증가 (시작 1~2마리) → 적 수 상한 도달, 적 수 고정
  → 적 기물 등급 상승: Pawn급 → Knight급 → Bishop급 → Rook급 → Queen급 → King급
  → King 보스 처치 시 그 스테이지 클리어 (승리 종료 — 로스터 소진 패배와 별개)
```

**왜 6×6인가**: 더 작은 판(3×3)은 Knight를 중앙에서 합법 이동 0개로 만드는 소프트락이 있습니다(§6.4.2). 판을 고정한 이유는, 판이 레벨마다 커지는 구조였을 때 기동성 격차가 무한 발산하고(Rook 기동성 = 2×(n-1) 공식, n이 커질수록 격차도 무한 확대) 근접 기물의 난이도가 레벨마다 누적 폭증했기 때문입니다. 고정하면 격차가 §4.3의 확률적 전투 시스템으로 다룰 수 있는 **상수**가 됩니다. 부수 효과로 매 레벨 새 판 지형을 학습할 필요가 없어 조작이 더 직관적입니다.

**적 수는 반드시 유한 상한이 있어야 합니다.** "계속 증가"에 상한이 없으면, 보드가 영구히 36칸 고정인 이상 **비둘기집 원리로 반드시 "필요 적 수 > 35"인 레벨이 존재**합니다 — 곡선을 아무리 완만하게 잡아도 문제를 늦출 뿐 제거하지 못합니다(수학적으로 증명됨, 실험적으로 발견된 문제가 아님). 상한값은 6×6에서 **10~14선 근방으로 잠정**(정확한 값은 §12 결정론 시뮬 대상). 스폰 스케줄러에 "가용 칸 초과 시 레벨 거부" 가드를 필수로 둡니다.

**상한 도달 후: 적 기물 등급 상승.** 적 수는 고정하고, 대신 적의 "기물 등급"을 올립니다. 적도 플레이어와 동일한 6종 기물 무브셋 + 특수능력 테이블(§6.4)을 그대로 재사용합니다 — 별도 적 전용 밸런스를 만들지 않습니다. Bishop 색맹 규칙(§6.4.2)은 적에게도 대칭 적용됩니다 — 적 스폰 색 제한은 말 타입에 무관하게 모든 적 스폰에 적용되므로 적 Bishop도 자동으로 보호됩니다.

**King급 구성 — 보스 슬롯.** 실제 체스는 King이 1개뿐이므로, King급 레벨은 **King 보스 1기 + 나머지는 하위 등급 잡몹**으로 구성합니다(캡 전체가 동시에 King 타입이 되면 방어 최강·사거리 최저 개체가 10여 마리 몰려 소모전 교착이 생기므로 채택하지 않았습니다). 잡몹 구성 비율은 §12 시뮬 튜닝 대상.

**King 보스 처치 = 스테이지 클리어.** 로스터 소진 패배와는 별개의 승리 종료 조건입니다. King 보스의 HP는 **플레이어 목숨(피스) 교체 간 유지**됩니다 — 리셋되면 로스터를 몇 개 사든 의미가 없어져 "컬렉션=목숨" 핵심 약속(§4.1)이 무너지기 때문입니다.

**Mutual-KO 판정 순서**: 같은 교환(내 공격 이동 → 양방향 데미지)에서 King 보스의 마지막 처치와 내 마지막 목숨 사망이 동시에 성립할 수 있습니다. **승리 판정을 먼저 평가**합니다 — 그게 King 보스의 마지막 처치라면 반격 데미지 적용 전에 즉시 스테이지 클리어로 확정합니다(반격 데미지는 기록·연출상으로만 처리, 결과를 뒤집지 않습니다).

**스폰 밀도 가드**: 6×6에서 "모든 칸이 점유되거나 King(인접 1칸) 인접"이 되는 데는 최소 4기(King-도미네이션 수)만 있으면 됩니다. 적 수 상한(10~14)은 이 최소값의 2.5~3.5배라 이론상 완전 지배 배치가 가능해, 안전 리스폰·zugzwang 대응이 전제하는 "안전 칸은 항상 존재"가 수학적으로 깨질 여지가 있습니다(필연은 아니고 스포너 설계에 달림). 스폰 시점에 "가용 칸 초과 시 레벨 거부" 패턴을 재사용해 **완전 지배 배치 금지 가드**를 추가합니다.

### 6.4 기물별 정체성과 밸런스

체스 기물의 **이동 규칙을 전투 문법으로 전환**합니다. 이동·기동성에는 위계가 있으나, 특수능력과 확률적 전투 해결로 상위 말이 하위 말을 반드시 이기지는 않습니다.

#### 6.4.1 기물 표

| 기물 | 이동 | 특수능력 | 가격 논리 |
|---|---|---|---|
| Pawn | 4방향 중 1칸 (고정 전진 아님 — 아래 참조). **조건 충족 시 승격**(승급 메커닉 자체는 확정, 트리거 조건은 미정 — §12 항목5) | 없음 (기준점) | 최저가 |
| Knight | L자 이동, 슬라이딩 기물의 차단을 무시 | 돌진 공격 — L자로 도착·공격 시 크리티컬 확률 2배(30%) | 저가 |
| Bishop | 대각선, BLOCKED. **판 36칸 중 자기 색 18칸만 영원히 도달 가능**(색맹, 아래 참조) | 장대각 조준(작업가설) — 이번 턴 대각 이동거리 기반 크리티컬: `min(15%+5%×(거리−1), 30%)`, Knight 고정값(30%)에서 캡 | 중가 |
| Rook | 직선, BLOCKED | 관통 공격(작업가설) — 직선 경로상 첫 번째 적 관통 시 두 번째 적까지 피해 | 중가 |
| Queen | 전 방향(직선+대각선), BLOCKED | 없음(전방위 공격은 이동 규칙 자체에서 이미 나옴) — 대신 **피격 데미지 항상 ×1.5** | 위험 프리미엄(고가) |
| King | 인접 1칸만 | 없음 — 대신 **피격 데미지 항상 ×0.5** | 안전 프리미엄(최고가) |

**공유 전투 변수 3개**: 각 기물의 특수능력은 이 중 정확히 하나만 조정합니다 — ① 크리티컬 확률(Knight·Bishop) ② 관통 대상 수(Rook) ③ 피격 데미지 배율(Queen·King). 새 서브시스템을 만들지 않고 기존 세 레버 안에서만 움직입니다. 모든 특수능력은 **자동 발동**(이동 패턴에 결부, 플레이어 추가 조작 없음)입니다.

Rook의 관통과 Bishop의 계수·캡은 확정 수치가 아니라 작업 가설입니다 — §12 결정론 시뮬로 실제 승률 곡선을 뽑은 뒤 조정합니다. Queen·King의 ×1.5/×0.5는 **항상 켜짐**(조건부 발동이 아님)으로 확정했습니다 — 안전 플레이로 회피할 구멍이 없어 조건부 설계보다 견고합니다.

> ⚠ **크리티컬 발동 시 피해 배율은 아직 미정**입니다 — 지금까지 정의된 건 크리티컬 **확률**뿐, 터졌을 때 데미지를 몇 배로 줄지는 없습니다. 절대적인 전투력 계산은 이 값 없이는 불가능합니다(§12).

> ⚠ **이 시스템이 해결하는 범위는 제한적입니다.** 특수능력·크리티컬은 **전투가 성사된 이후의 결과**만 확률화합니다. King·Knight처럼 이동 범위가 좁은 말이 **적에게 도달하기까지 걸리는 턴수**(reachability) 문제는 별개입니다 — 이건 해소된 게 아니라, 보드를 6×6으로 고정한 덕분에 레벨마다 무한히 나빠지지 않고 **유한한 값으로 bound**된 것뿐입니다. §12 결정론 시뮬에 "첫 교전까지 턴수" 지표를 추적하는 이유가 이것입니다.

#### 6.4.2 보드 크기별 기동성 (계산값, 빈 판 기준)

| 보드 | Pawn | Knight | Bishop | Rook | Queen | King |
|---|---:|---:|---:|---:|---:|---:|
| 3×3 | — | 1.8 (최소 0) | 2.2 | 4.0 | 6.2 | 4.4 |
| 4×4 | — | 3.0 (최소 2) | 3.5 | 6.0 | 9.5 | 5.2 |
| 5×5 | — | 3.8 (최소 2) | 4.8 | 8.0 | 12.8 | 5.8 |
| **6×6 (채택)** | **3.33 (최소 2)** | **4.4 (최소 2)** | **6.1** | **10.0** | **16.1** | **6.1** |

3×3은 Knight를 소프트락시킵니다(중앙 합법 이동 0개, L자 이동이 전부 판 밖). 4×4부터 최소 2로 회복되고 6×6에서도 유지됩니다. **6×6 고정 기준 격차는 상수입니다**: Queen:Knight = 3.66배, Rook:Knight = 2.27배, King:Knight = 1.39배 — 판이 커지지 않으므로 레벨과 무관하게 고정되고, 이게 특수능력·크리티컬 보정이 메워야 할 목표치입니다.

**Pawn 이동 규칙**: 정통 체스의 "고정 전진"은 2인 대전을 전제로 방향이 명확하지만, 이 게임은 PvE에서 적이 사방에서 스폰되므로 "전진"이 정의되지 않습니다. 고정 전진 해석은 평균 기동성 0.83, **판 가장자리에서 합법 이동 0개**(3×3 Knight와 동일한 소프트락 패턴)를 냅니다. **4방향 중 1칸으로 확정** — 평균 3.33, 최소 2, PvE 논리에도 부합합니다.

**Bishop 색맹 구조**: 대각선 이동은 판의 색(좌표 패리티)을 절대 바꾸지 않습니다. BFS로 다중 이동 누적 도달 범위를 계산하면 Bishop은 몇 수를 두든 **36칸 중 18칸(정확히 절반)에만 영원히 도달 가능**합니다(Rook·Knight는 36/36). 말 1기 = 목숨인 이 게임에서, Bishop이 배정된 목숨은 반대 색 칸에 스폰된 적에게 이동으로도 관통으로도 영원히 도달 못 합니다(관통도 대각선을 타므로 같은 색만 훑음) — 방치하면 소프트락입니다.

완화안: **Bishop이 배정된 동안 적 스폰을 같은 색 칸으로 제한**합니다. 이 완화안 자체에 구멍이 두 개 있어 함께 처리합니다 — ① 활성 말이 Bishop으로 바뀌는 순간, 다른 말이 살아있을 때 스폰돼 색 제한이 안 걸렸을 수 있는 반대색 잔존 적을 같은 색으로 **재배치**(HP·상태 유지, 신규 생성 아님)합니다. ② 6×6=36칸이 색상으로 정확히 18/18 양분되고 플레이어가 1칸을 차지하므로 Bishop 레벨의 실질 가용 칸은 17칸(다른 기물은 35칸)입니다 — 적 수 상한과 결합하면 다른 기물 대비 항상 2배 밀도가 되므로, **Bishop이 활성일 때는 적 수 상한을 다른 기물의 절반으로 적용**합니다. (별도 스탯 보정은 하지 않습니다 — 상한 이후 난이도 레버 자체가 스탯이 아니라 기물 등급 상승이기 때문입니다, §6.2.)

#### 6.4.3 가격 논리 — 위험 프리미엄과 안전 프리미엄

King이 가장 비싼 이유는 "가장 어려워서"가 아닙니다 — King의 기동성(6.1)은 Knight(4.4)·Bishop(6.1)과 같거나 높아 "어렵다"는 서술이 기동성 지표와 애초에 맞지 않았고, 여기에 **항상 켜진 최강 방어**(피격 ×0.5)까지 있으면 실수 비용이 반으로 줄어 오히려 다루기 쉬운 말이 됩니다.

**가격 논리를 다음으로 교체합니다**: King은 "가장 안전해서"(낮은 화력·낮은 분산·높은 생존, 방어형 보험 픽) 비싸고, Queen은 "강하지만 위험해서"(높은 화력·최고 기동성, 최약 방어) 비쌉니다. 가격 = 난이도 게이트라는 단일 서술 대신, **기물마다 "위험한 강함"과 "안전한 약함" 두 가지 프리미엄 축**을 인정합니다.

### 6.5 초월(Transcendence) — 프레스티지 재도전

스테이지 클리어(King 보스 처치) 후, 플레이어는 **같은 진행 사다리를 더 어렵게 재도전**할 수 있습니다.

- **보유 로스터는 초월 레벨 전환 시 유지**됩니다 — 완전 리셋 프레스티지가 아니라 **난이도 선택에 가까운 구조**(벤치마크 Anime Card Clash의 Nightmare Mode 패턴과 동일 계열).
- 적 스탯 배율이 초월 레벨 번호에 연동됩니다: 초월 레벨 1(기본) = ×1, 초월 레벨 2 = ×2. 3 이상은 선형 ×N 작업 가설(두 지점만 확정, §12 시뮬 대상).
- **이 배율은 적의 베이스 스탯(HP·ATK)에만 적용**되며, 특수능력의 배율(크리티컬 확률, 피격 데미지 ×0.5/×1.5, 관통)에는 **곱연산되지 않습니다** — 두 배율 체계가 겹치면 초월 티어 상승이 지수적으로 폭주할 위험이 있어 명시적으로 분리했습니다.
- 적 수 상한·기물 등급 사다리 자체는 초월 레벨과 무관하게 동일하게 반복됩니다.

#### 🔴 초월 벽 — 수학적으로 증명된 유한 상한

적 스탯이 초월 티어 N에 선형 비례하는데, 플레이어 측 파워는 성장 수단이 전무했습니다(말 구매는 목숨 +1일 뿐, 스탯이 아님). "처치 필요 턴수"는 N에 비례해 늘고 "생존 가능 턴수"는 N에 반비례하므로, 방향이 반대인 두 단조함수는 **임의의 양의 베이스라인 상수에 대해 반드시 한 지점(N\*)에서 교차**합니다. 그 이후로는 어떤 기물을 뽑아도 벽 자체가 없어지지 않습니다 — "초월 = 무한 프레스티지"라는 전제가 구조적으로 거짓이었습니다(실험적 우려가 아니라 수학적 증명).

**해결책: 플레이어 파워 성장 메커니즘 신설.** §6.3의 "영구 강화" 구매가 이 벽에 대응하는 유일한 수단입니다. 재화의 용도가 "목숨 늘리기"와 "파워 늘리기" 두 갈래로 분리됩니다. 정확한 성장 곡선(벽을 실제로 얼마나 밀어내는지)은 §12 결정론 시뮬 대상 — 최소한 벽이 "존재는 하되 계속 밀려난다"를 목표로 튜닝합니다.

이 결정으로 두 부수 문제도 완화됩니다 — ① "랜덤 배정이 King(벽 근처 유일 생존 수단) 조종을 RNG에 맡긴다"는 우려는 King이 유일한 생존 수단이 아니게 되면 약화됩니다. ② "방어 쿠션이 없는 하위 랭크(Pawn~Rook)가 King보다 먼저 벽에 부딪힌다"는 우려도, 파워 성장이 사다리 전 구간에 균일 적용되므로 완화됩니다. 단, §12 시뮬에서 **랭크별 N\* 산출**을 필수 항목으로 유지해 실제로 고르게 밀렸는지 검증합니다. 적 랭크 순서가 실제로 난이도 단조증가인지도 미검증입니다(King 기동성이 Queen보다 낮음 — 단, 보스 슬롯 구조상 실제 위협은 King+잡몹 총합이라 완화됨).

### 6.6 스코프 판단

§6.2·§6.5의 매크로 시스템(기물 등급 상승·King 클리어·초월·영구 강화) 전체는 **v1**입니다. MVP는 "죽을 때까지"만 보는 순수 리텐션 검증 루프이고(§3.2), 여기에 승리 조건·프레스티지까지 얹으면 MVP가 검증하려는 단일 가설이 흐려집니다. MVP 3종(Pawn/Knight/Rook)은 적 수 상한·King 클리어 없이, 상한 후 정체·로스터 소진까지 생존하는 단순 구조로 갑니다.

## 7. 리텐션 설계 (v1 이후)

1. **컬렉션 = 목숨 (본 게임 고유의 최강 훅)**
   일반적인 수집 게임은 "다 모으면 끝"이지만, 여기서는 수집이 런 깊이로 직결되고 각 말이 다른 플레이 경험을 줍니다. 벤치마크가 지목한 붕괴 원인("컬렉션 완성 = 이탈")에 대한 구조적 방어. 근거: Pet Simulator 99 "2,000+ 펫" CCU 163,141, Sol's RNG "400+ 오라" CCU 31,010. 적용: dex UI를 v1에 탑재, `6 기물 × N 스킨 × 레어도`.

2. **시즌제 Elo 래더 + 하드 리셋 + 랭크 전용 코스메틱**
   근거: Blade Ball(시즌마다 Elo 전원 초기화 + 랭크 게이트 스킨, CCU 13,344), RIVALS(시즌 2~3개월, CCU 202,868). 적용: 8주 시즌, Elo 전체 리셋, 티어별 시즌 한정 스킨 1종.

   **랭크 공정성 — 정규화 공용 풀.** 유료 P2W가 없어도 로스터를 다 모은 고인물은 목숨 수에서 우위를 가지므로, 보유 로스터로 랭크를 치르면 Elo가 배치 실력이 아니라 투자 시간을 측정하게 됩니다. 랭크는 전원 전체 로스터로 입장합니다. 수집(dex)은 PvE·코스메틱 축, 랭크는 순수 실력 축으로 완전 분리합니다.

3. **재방문율 최적화 (`top-revisited`)**
   근거: The Battle Bricks(CCU 7,420)가 Roblox 자체 `top-revisited` 정렬에 노출 — 알고리즘 무료 배포. 적용: CCU 스파이크가 아닌 D1/D7 복귀율을 최적화 대상으로.

4. **일일 로그인 — 직접 만들지 말 것**
   근거: Roblox 1차 제공 Engagement Rewards 기능 패키지(클라·서버 로직 + UI + Daily/Time 타입 + 스트릭 리셋). 적용: 패키지 투입, 엔지니어링 0. 노력은 보상 내용물에만.

5. **트레이드 — 보류**
   유료 가챠 + 트레이드 = 미성년 대상 환금성 루트박스 구조. 출시 시 코스메틱 한정 + 유료 뽑기 획득물 영구 거래 불가. v2 이후 검토.

**템플릿: Tower Defense Simulator** (코스메틱 크레이트로 7년 생존).

|---|---|---|
| 공격 모션 스킨 크레이트 | Dev Product | 공격 모션만 변경. Basic(게임 재화) / Premium·Deluxe(Robux) |

| 보드·VFX·처치 연출 | Dev Product | 두 번째 코스메틱 축 |

| 이벤트 한정 크레이트 | Dev Product | 재출시 없음 (FOMO) |

가격: 진입 25~99 Robux → 프리미엄 1,000+ Robux, 4~6단 티어, 중·상위에 "best value" 앵커.

### 8.2 절대 금지선

- 체스말을 현금으로 판매 금지. 말 = 목숨이므로 이는 곧 목숨 판매 = P2W.
- **게임 내 재화를 현금으로 판매 금지.** 재화로 말을 사므로, 재화 판매 = 우회적 목숨 판매입니다. 코스메틱 전용 원칙을 무너뜨리는 가장 흔한 뒷문이므로 명시 차단.
- 목숨·부활·컨티뉴를 유료로 판매 금지.
- 랭크 매치에 유료 요소 유입 금지 (출시 제약이지 v2 수정사항 아님).
- Robux → 거래 가능 가치 경로 생성 금지.

## 9. 컴플라이언스 — 필수 엔지니어링 (협상 불가)

> **코스메틱 가챠도 규제 면제가 아닙니다.** Roblox "Paid Random Items" 정책은 Robux(및 Robux 파생 재화)로 구매하는 **모든** 무작위 아이템에 적용됩니다.

| 요구사항 | 구현 |
|---|---|
| 확률 공시 | 모든 결과 + 실제 수치 확률(합계 정확히 100%), 구매 전 노출 |
| 정책 API | `PolicyService:GetPolicyInfoForPlayerAsync()` 호출 필수 |
| 지역 제한 | `ArePaidRandomItemsRestricted` 준수 → 비무작위 대체 경로 필수 |
| 거래 제한 | `IsPaidItemTradingAllowed` 준수 |
| 미준수 결과 | 해당 지역에서 게임 자동 이용불가 |

**현재 차단 지역**: 영국 18세 미만, 호주 전체 유저. 확대 추세.

**한국**: 게임산업진흥법 법률 제19242호(2024-03-22 시행). 간접 구매(Robux로 산 게임 내 재화)까지 포함. 위반 시 최대 징역 2년 / 벌금 2,000만원. 연평균 매출 1억원 이하 소규모 사업자 면제.

**설계 반영**: 확률 테이블을 데이터로 정의하고 클라이언트 렌더, 배너별 버전 관리. 비무작위 경로(색상·장식 직접 구매)를 차단 지역 대응 경로로 승격. `[Medium]` 출시 전 법률 검토 필요 — 본 문서는 법률 자문이 아닙니다.

**주의**: 런 시작 시 **말 랜덤 배정은 유료 무작위가 아닙니다**(게임플레이 장치, 결제 무관). Paid Random Items 정책 대상은 코스메틱 크레이트뿐입니다. 이 구분을 구현·심사 시 명확히 유지합니다.

## 10. 기술 아키텍처

`00_VS`의 코드를 복사하지 않고, **동일 스택·패턴으로 `01_Chess/`에 신규 스캐폴딩**합니다.

### 10.1 스택
- **rokit** 툴체인 핀: rojo 7.7.0 / lune 0.10.5 / selene 0.31.0 / stylua 2.5.2
- Rojo 소스 트리 → `.rbxlx` 빌드
- Lune 기반 dual-runtime 테스트

### 10.2 원칙
- **서버 권위**: 전투 판정·보상·재화·구매·랜덤 배정 전부 서버 소유. 클라이언트 결과 불신.
- **랜덤 배정은 반드시 서버에서.** 클라이언트가 배정을 굴리면 원하는 말이 나올 때까지 재시도하는 치트가 성립합니다. 리롤 횟수도 서버 상태.
- **순수 결정론 Rules 모듈**: Roblox 인스턴스 의존 0 → 단위 테스트 가능.
- **전투 확률(크리티컬 등)도 결정론 대상.** 시드 기반 RNG를 런 상태의 일부로 취급 — 같은 시드는 같은 특수능력·크리 결과를 재현. RNG 소비 순서까지 상태에 포함해야 리플레이가 깨지지 않습니다.
- **RemoteEvent 토큰 검증**: 클라이언트는 서버 발급 토큰 + 선택지 ID만 제출.
- **속성 기반 리플리케이션**: 권위 상태는 서버 전용.
- **DataStore**: 보유 말·재화·진행도·dex·Elo·코스메틱 소유권·영구 강화 영속화.
- **MarketplaceService**: 게임패스/개발자상품 + 영수증 검증.

### 10.3 결정론의 부수 효과
전투가 완전 결정론이면 `(초기 상태 + 시드)`로 재현 가능 → 리플레이 공유(바이럴)·서버 검증(안티치트)·재현 가능한 밸런스 테스트가 **하나의 설계**에서 나옵니다.

## 11. 범위 (Scope)

### MVP (리텐션 검증 전용)
- 런 루프(§6.1) + 메타 재화·말 구매(§6.3, 영구 강화 제외)
- 턴제 이동 선택 + 자동 전투 해결 (핵심 검증 대상)
- 6×6 고정 보드 + 레벨별 적 수·스탯 증가 (적 수 상한 후 **정체**, 기물 등급 상승·King 클리어 없음 — v1로 이연)
- 기물 3종으로 시작(Pawn/Knight/Rook), 각자 특수능력 포함. 이동 문법이 서로 가장 다른 조합. 6종 전체(Bishop/Queen/King)는 v1
- 특수능력 자동 발동 + 기준 크리티컬 15%
- 랜덤 배정 + 리롤 1회 (서버 권위)
- 목숨 소진 → 런 종료 → 정산 → 재구매
- dex 카운터
- 계측 3종
- **수익화 없음. PvP 없음. 시즌 없음.**

### v1 (MVP 통과 시)
- 기물 6종 완성
- 적 기물 등급 상승 + King 클리어 + 초월(프레스티지) 레벨 + 영구 강화(§6.2·§6.5)
- 코스메틱 수익화 전체(§8) + 컴플라이언스(§9)
- Engagement Rewards 일일보상
- 시즌제 Elo 래더(§7-2)

### v2 이후
- PvP (실시간 또는 비동기)
- 제한적 트레이드 (코스메틱 한정)
- 이벤트 캘린더

## 12. 남은 리스크와 미결 사항

브레인스토밍 4라운드 + 데빌스 애드버킷 검증을 거치며 발견된 결함은 대부분 본문에 해결책이 반영되어 있습니다(§6). 아래는 **아직 열려 있는 항목**만 정리합니다 — 전부 개발 착수를 막지 않으며, 시뮬레이션 튜닝 또는 다음 개발 단계 자연 이관 대상입니다.

| # | 항목 | 심각도 | 내용 |
|---|---|---|---|
| 1 | Elo 래더(v1) - PvP(v2 이후) 스코프 정합성 | High | v1에 Elo가 있는데 PvP 자체는 v2 이후라 정의상 모순. PvP 최소 스펙을 v1 착수 전 확정하거나 Elo를 v2 이후로 재배치 |
| 2 | MVP 3종의 최악 케이스 검증 공백 | Medium | Queen/King이 MVP에 없어 실제 최대 기동성 격차(3.66배)가 검증 안 됨. v1 게이트 조건 검토 |
| 3 | 적 AI 행동 규칙 | Medium | 이동 로직(플레이어 추적 방식 등) 미정. 데미지 트리거는 확정됐으나 어디로 이동하는지는 없음. 비인접 합법수 1개 보장(§6.1) + 완전 지배 배치 금지(§6.2)를 필수 요구사항으로 포함. **MVP 착수 전 최소 규칙 필요** |
