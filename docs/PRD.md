# PRD — Roblox 체스말 오토배틀러 (작업명: 01_Chess)

**버전** 0.1 (초안) · **작성** 2026-07-23 · **근거** [BENCHMARK.md](BENCHMARK.md) (Roblox 1차 API 45개 타이틀, 2026-07-23 수집)

> 이 문서는 `01_Chess/` 단독 프로젝트용입니다. `00_VS`(Nightfall survivors)와 **무관**하며 그 폴더를 건드리지 않습니다.

---

## 1. 제품 정의

플레이어의 캐릭터가 **체스말이 되어** 보드 위에 배치되고, 자동으로 전투하는 **PvE 우선 오토배틀러**.

한 줄 요약: **체스는 실력 레이어, 가챠는 코스메틱 레이어.**

핵심 차별점은 "어떤 말을 소유했는가"가 아니라 **"어디에 놓았는가"**가 승패를 가르는 것. 벤치마크상 Roblox의 모든 스케일 타이틀은 전자에 의존하며, 그래서 컬렉션을 완성하는 순간 게임이 끝나고 붕괴합니다.

## 2. 근거 — 왜 이 게임인가

### 2.1 갭 (검증됨)

벤치마크 리서치 결과:

```
[NULL RESULT] TFT / auto-chess style round-draft auto-battler on Roblox
→ 발견된 것 없음
```

Roblox에는 **경로/레인형 자동전투 게임은 수십 개**(Anime Expeditions, Vanguards, UTDZ, ASTD…) 있으나, **바운디드 보드 위 공간 배치가 주된 실력 표현이자 진행 축인 게임은 없습니다.**

### 2.2 인접 시장 규모 (실측, `games.roblox.com/v1/games`, 2026-07-23)

| 타이틀 | CCU | 누적 방문 | 의미 |
|---|---:|---:|---|
| Tower Defense Simulator | 21,357 | 48.6억 | **코스메틱 전용의 7년 생존 증명** |
| Anime Squadron ("lane battler", 배치 페이즈 있음) | 8,056 | 7,726만 | **현실적 base case** (1년 미만) |
| The Battle Bricks (유닛 드래프트 오토배틀러) | 7,420 | 1.22억 | Roblox `top-revisited` 정렬 진입 |
| Garden Tower Defense (**그리드** 배치) | 6,501 | 7.61억 | 어린 유저가 그리드를 이해함 |
| Anime Paradox X | 1,137 | 2,813만 | **median 2025 신규 진입 결과 (하방 시나리오)** |

### 2.3 체스 자체는 Roblox에서 작다 (전제 검증)

| 타이틀 | CCU | 누적 방문 |
|---|---:|---:|

| Chess Club | 97 | 2,116만 |

**해석**: 1.06억 방문 = 잠재 관심은 실재. 435 CCU = **리텐션·수익화 설계 부재**. 정통 체스로는 안 되고, 오토배틀러 루프를 얹어야 한다는 근거.

### 2.4 유닛 가챠 붕괴 곡선 (우리가 피하는 것)

| 타이틀 | 누적 방문 | 현재 CCU |
|---|---:|---:|

| Anime Defenders | 34.3억 | **394** |
| Anime Adventures | 25.1억 | 145 |
| Anime Vanguards | 20.0억 | 10,060 |

전부 유닛 가챠. **누적 방문 수십억 → CCU 수백**. 원인: 가챠가 메타 전부일 때, 0.005% 유닛을 얻는 순간 게임이 끝남.

## 3. 목표 및 성공 지표

### 3.1 최종 목표
Roblox DevEx 실수익. **단, 이는 상위 1% 미만 결과**임을 명시 — 기본 시나리오가 아님.

수익 구조 실측:
| 항목 | 값 |
|---|---|
| DevEx 환전율 | $0.0038 / earned Robux |
| 최소 환전 | 30,000 Robux ≈ **$114** |
| 플랫폼 수수료 | 30% (개발자 70%) |
| **실수령** | 유저 결제액의 **약 1/4** |

### 3.2 MVP의 유일한 임무
**"보드 배치가 재플레이 충동을 만드는가?"** 이 질문에만 답합니다. 수익화·PvP·시즌 전부 이후.

계측 지표 3개:
1. **restart-after-loss rate** — 패배 후 즉시 재시작 비율 (가장 중요)
2. **rounds per session**
3. **D1 / D7 리텐션**

### 3.3 킬 크라이테리아
restart-after-loss가 기준 미달이면 **경제 시스템 구축 전에 프로젝트 중단**. 벤치마크의 실패 시그니처: Battle Pet — 좋아요 157,828, **CCU 445**. "첫 접촉엔 좋아하고 이틀째 떠남." 이게 우리가 재현할 기본값이며, 데이터로 반증해야 합니다.

> ⚠ 구체 임계값(예: restart ≥ 50%, D1 ≥ 30%)은 **벤치마크에서 나온 수치가 아님** `[Low]`. 소프트런치 실측으로 캘리브레이션 필요.

### 4.1 코스메틱 전용 결정의 근거 (증거 보강)

벤치마크 종합 에이전트는 유닛 가챠(b)를 권고했으나, **다음 증거가 코스메틱 전용을 지지**합니다:

- **Tower Defense Simulator**: 코스메틱 크레이트 중심, **7년 · 48.6억 방문 · CCU 21,357 안정**. 45개 타이틀 세트에서 **붕괴하지도 급등하지도 않은 유일한 타이틀**.
- **규제 리서치 결론**: `random power + 미성년자 + 루트박스` = 최대 노출 조합. 향후 규제·플랫폼 제재 1순위 표적.
- **플레이어=체스말**이므로 모든 코스메틱이 보드 위에서 상시 노출됨 → 코스메틱 수익화의 전제 조건 충족.

**트레이드오프 명시**: 코스메틱 전용은 ARPDAU 상한이 낮고, 순수 pull 게임(Anime Card Collection: 7개월 1.42억 방문)에 초기 획득 경쟁에서 밀릴 수 있습니다. 우리는 **"12~18개월 스파이크 후 사망" 대신 "느리지만 durable"**을 선택했습니다.

## 5. 코어 게임 루프 (MVP)

```
Offer → Place → Fight → Reward → Escalate → Restart
```

| 단계 | 내용 |
|---|---|
| **Offer** | 약 12종 풀에서 말 3개 제시, 1개 선택. **무료 pull** — 유료화 전에 충동 존재 여부를 공짜로 검증 |
| **Place** | 보유 말을 그리드(시작 **5×5**)에 배치. **인접·사선/직선 사거리가 결과를 눈에 띄게 바꿔야 함** |
| **Fight** | 결정론적 자동 전투, 약 20~30초, 플레이어 입력 없음 |
| **Reward** | 골드 + dex 해금. **"N / 전체" 수집 카운터 상시 노출** |
| **Escalate** | 다음 웨이브 난이도 상승 |
| **Restart** | 원 탭 재시작, 오퍼 풀 재추첨 |

**MVP에서 제외**: 가챠, Robux SKU, PvP, Elo, 시즌, 트레이드, 일일보상.

### 5.1 체스말 → 오토배틀러 역할 매핑

체스 기물의 **이동 규칙을 공격 패턴으로 전환** — 이것이 "체스말 오토배틀러"를 하나의 일관된 디자인으로 묶는 핵심 장치입니다.

| 기물 | 전투 역할 | 공격 패턴 |
|---|---|---|
| Pawn (졸) | 저가 전열 | 전방 인접 1칸, 조건 충족 시 승격 |
| Knight (나이트) | 후열 침투 | L자 도약 — 전열 무시하고 후방 타격 |
| Bishop (비숍) | 사선 원거리 | 대각선 라인 관통 |
| Rook (룩) | 직선 딜러/탱커 | 직선 라인 관통, 높은 체력 |
| Queen (퀸) | 고가치 에이스 | 전 방향 |
| King (킹) | 지휘/오라 | 인접 아군 버프, 사망 시 즉시 패배 |

이 매핑 덕분에 **배치가 곧 실력**이 됩니다. 나이트를 어디 두면 적 후열에 닿는지, 룩의 직선을 어떻게 여는지가 승패를 가름.

> ⚠ **설계 리스크** `[Medium]`: "그리드 배치를 어린 유저가 이해한다"는 근거는 Garden Tower Defense의 **지표는 검증됐으나 게임플레이 해석은 미검증**입니다. 보드 설계를 여기에 의존하기 전에 직접 플레이 확인 필요. 또한 *배치 자체가 재미있는가*는 세트 내 어떤 타이틀도 증명하지 못했습니다.

## 6. 리텐션 설계 (v1 이후)

벤치마크 랭킹 순:

1. **시즌제 Elo 래더 + 하드 리셋 + 랭크 전용 코스메틱**
   근거: Blade Ball(시즌마다 Elo 전원 초기화 + 랭크 게이트 스킨, CCU 13,344 / 62.9억 방문), RIVALS(시즌 2~3개월, CCU 202,868).
   적용: **8주 시즌, Elo 전체 리셋, 티어별 시즌 한정 말 스킨 1종.**

   ⚠ **랭크 공정성 — 정정된 설계.** 초안에는 "전투력이 100% 플레이 획득이므로 랭크가 자동으로 공정"이라 적었으나 **이는 오류**입니다. 유료 P2W가 없어도, 로스터를 전부 보유한 고인물은 신규 대비 **선택지 수**에서 우위를 가집니다. 그러면 Elo는 *배치 실력*이 아니라 *투자 시간*을 측정하게 되고, "체스이므로 Elo가 정당하다"는 본 기획의 핵심 논지가 무너집니다.

   ✅ **확정: 정규화 공용 풀.** 랭크 매치는 모든 플레이어가 **전체 로스터를 사용 가능한 상태로 입장**합니다. 이 구조는 가챠가 없어도 필요하며, 부수 효과로 **"컬렉션 완성 = 이탈"** 붕괴 곡선도 차단합니다 — 시즌 리셋은 Elo를 초기화하되 로스터는 건드리지 않으므로, 재도전 동기가 수집 완료 이후에도 남습니다.

   **설계 함의**: 수집(dex)은 **PvE 진행·코스메틱·완성 욕구**의 축이고, 랭크는 **순수 배치 실력**의 축으로 완전히 분리됩니다. 두 축이 섞이지 않게 하는 것이 설계 초기 제약입니다.

2. **끝나지 않는 컬렉션 인덱스(dex)**
   근거: Pet Simulator 99 "2,000+ 펫" CCU 163,141, Sol's RNG "400+ 오라" CCU 31,010.
   적용: `6 기물 × N 스킨 × 레어도` 완성 그리드. **분모가 보이는 카운터를 v1에 탑재.**

3. **pull 루프 자체 + 확률(luck)을 가속제로 판매**
   근거: Sol's RNG는 루프를 "굴리기"로 축소하고도 20.2억 방문. Anime Card Clash는 Luck/Cooldown 트랙 판매.
   적용: **결과가 아니라 확률·추가 뽑기 횟수를 판매.** 우리 경우 대상은 전부 코스메틱이므로 P2W 여지 자체가 없음.

4. **재방문율 최적화 (`top-revisited`)**
   근거: The Battle Bricks(CCU 7,420)가 Roblox 자체 `top-revisited` 정렬에 노출됨 — 알고리즘 무료 배포.
   적용: CCU 스파이크가 아니라 **D1/D7 복귀율**을 최적화 대상으로 삼음.

5. **일일 로그인 — 직접 만들지 말 것**
   근거: Roblox 1차 제공 **Engagement Rewards 기능 패키지**(클라·서버 로직 + 기본 UI + Daily/Time 타입 + 스트릭 리셋 정렬).
   적용: 패키지 그대로 투입, 엔지니어링 0. 노력은 **보상 내용물**(뽑기 티켓·코스메틱 조각)에만.

6. **트레이드 — 보류**
   근거: MM2(CCU 296,610), Adopt Me(CCU 261,565) 모두 트레이드 경제.
   **제약**: 유료 가챠 + 트레이드 = 미성년 대상 환금성 루트박스 구조. **출시 시 코스메틱 한정 + 유료 뽑기 획득물은 영구 거래 불가.** v2 이후 검토.

## 7. 수익화 설계 (v1)

**템플릿: Tower Defense Simulator** (코스메틱 크레이트로 7년 생존).

### 7.1 SKU 구조

Roblox 결제 수단 선택 규칙 (1차 문서 기준):
- **Game Pass** = 1회성 영구 해금 (소유 중복 자동 처리). 매출 비중 약 55%.
- **Developer Product** = 반복 구매 (재화·뽑기). 매출 비중 약 30%.

| SKU | 유형 | 내용 |
|---|---|---|
| 말 스킨 크레이트 | Dev Product | **공격 모션 변경** 스킨. 티어: Basic(플레이 획득 재화) / Premium·Deluxe(Robux) |
| 색상 커스텀 | Game Pass | **유료 전용** 색상 팔레트 해금 |
| 장식 무기 | Game Pass / Dev Product | 외형 전용, 전투력 0 |
| 보드·VFX·처치 연출 스킨 | Dev Product | 두 번째 코스메틱 축, 밸런스 리스크 0 |
| 시즌 패스 | Game Pass | 약 400~800 Robux, 8주 Elo 시즌 연동 |
| 럭 / 추가 뽑기 | Dev Product | **확률·횟수 판매** (코스메틱 대상) |
| 이벤트 한정 크레이트 | Dev Product | 재출시 없음 (FOMO) — TDS 7년 검증 |
| Roblox Premium 보너스 | — | Premium 유저 추가 혜택 → Premium Payouts 부가 수익 |

가격 아키텍처: 진입 25~99 Robux부터 프리미엄 1,000+ Robux까지 **4~6단 티어**, 중·상위에 의도적 "best value" 앵커 배치.

### 7.2 절대 금지선
- 전투력에 영향을 주는 어떤 것도 판매하지 않음
- 랭크 매치에 유료 요소 유입 금지 (**출시 제약이지 v2 수정사항 아님**)
- Robux → 거래 가능 가치 경로 생성 금지

## 8. 컴플라이언스 — 필수 엔지니어링 (협상 불가)

> **코스메틱 가챠도 규제 면제가 아닙니다.** Roblox "Paid Random Items" 정책은 Robux(및 Robux 파생 재화)로 구매하는 **모든** 무작위 아이템에 적용됩니다.

| 요구사항 | 구현 |
|---|---|
| 확률 공시 | 모든 결과 + **실제 수치 확률, 합계 정확히 100%**, **구매 전** 노출 (3D 전시 또는 명시적 Details 팝업) |
| 정책 API | `PolicyService:GetPolicyInfoForPlayerAsync()` **호출 필수** |
| 지역 제한 | `ArePaidRandomItemsRestricted` 준수 → **비무작위 대체 경로 필수** |
| 거래 제한 | `IsPaidItemTradingAllowed` 준수 → false면 뽑기 획득물 거래 차단 |
| 미준수 결과 | **해당 지역에서 게임 자동 이용불가** |

**현재 차단 지역**: 영국 18세 미만, **호주 전체 유저**. 향후 확대 예상.

**한국**: 게임산업진흥법 법률 제19242호 (2024-03-22 시행). **간접 구매**(Robux로 산 게임 내 재화)까지 포함 — 정확히 우리 구조. 위반 시 최대 징역 2년 / 벌금 2,000만원. 연평균 매출 1억원 이하 소규모 사업자는 면제.

**설계 반영**:
- 확률 테이블을 **데이터로 정의**하고 클라이언트에서 렌더, **배너별 버전 관리**. 사후 개조는 비쌈.
- 비무작위 경로(색상·장식 직접 구매)는 이미 계획에 존재 → **차단 지역 대응 경로로 승격**.
- `[Medium]` 출시 전 법률 검토 필요. 본 문서는 법률 자문이 아님.

## 9. 기술 아키텍처

`00_VS`의 코드를 복사하지 않고, **동일 스택·패턴으로 `01_Chess/`에 신규 스캐폴딩**합니다.

### 9.1 스택
- **rokit** 툴체인 핀: rojo 7.7.0 / lune 0.10.5 / selene 0.31.0 / stylua 2.5.2
- Rojo 소스 트리 → `.rbxlx` 빌드
- Lune 기반 **dual-runtime 테스트** (Roblox 서비스 의존 없는 순수 모듈은 CI에서 실행)

### 9.2 원칙
- **서버 권위**: 전투 판정·보상·진행·상점 결과 전부 서버 소유. 클라이언트 결과 불신.
- **순수 결정론 Rules 모듈**: Roblox 인스턴스 의존 0 → 단위 테스트 가능. 자동 전투가 결정론이므로 리플레이·검증·안티치트가 동시에 해결됨.
- **RemoteEvent 토큰 검증**: 클라이언트는 서버 발급 토큰 + 선택지 ID만 제출 가능. 위조 페이로드는 상태 변경 전에 거부.
- **속성 기반 리플리케이션**: 권위 상태는 서버 전용, 클라이언트에는 표시용 속성만.
- **DataStore**: 코스메틱 소유권·진행도·dex·Elo 영속화 (신규 — `00_VS`에는 없던 영역).
- **MarketplaceService**: 게임패스/개발자상품 처리 + 영수증 검증.

### 9.3 결정론이 주는 부수 효과
자동 전투가 완전 결정론이면 `(초기 배치 + 시드)` 만으로 전투를 재현할 수 있습니다. → 리플레이 공유(바이럴), 서버 검증(안티치트), 재현 가능한 밸런스 테스트가 **같은 하나의 설계**에서 나옴.

## 10. 범위 (Scope)

### MVP (리텐션 검증 전용)
- 코어 루프 6단계 (§5)
- 6종 기물 + 약 12개 오퍼 풀
- 5×5 보드, 결정론 자동 전투
- dex 카운터
- 계측 3종 (restart-after-loss / rounds per session / D1·D7)
- **수익화 없음. PvP 없음. 시즌 없음.**

### v1 (MVP가 기준 통과 시)
- 코스메틱 수익화 전체 (§7) + 컴플라이언스 (§8)
- Engagement Rewards 일일보상 패키지 투입
- dex 확장 (스킨 × 레어도)
- 시즌제 Elo 래더 (§6-1)

### v2 이후
- PvP (실시간 또는 비동기)
- 제한적 트레이드 (코스메틱 한정, 유료 획득물 거래 불가)
- 이벤트 캘린더 운영

### 명시적 비목표
- 정통 체스 룰 재현 (§2.3 근거 — 상업적으로 실패한 경로)
- 전투력 판매
- 유닛 가챠
- 무제한 트레이드 시장
